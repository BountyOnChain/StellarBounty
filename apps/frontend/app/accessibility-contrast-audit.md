# Color Contrast Audit — WCAG AA

## Checklist
- [ ] Text / background contrast >= 4.5:1 for body text
- [ ] Large text / background contrast >= 3:1
- [ ] Non-text UI components / graphic objects >= 3:1
- [ ] Disabled states still meet minimum contrast
- [ ] Focus indicators visible at 3:1 minimum

## Notes
Use browser DevTools contrast checker after token updates.
