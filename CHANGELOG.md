## [0.1.0] - 2026-06-16

### Added

- Initial monorepo structure with frontend, backend, and Soroban contract workspaces.
- Frontend application for browsing bounties, creating bounties, submitting work, and reviewing submissions.
- Backend API workspace for authentication, bounty management, user flows, submissions, metrics, and blockchain-related services.
- Smart contract workspace for Stellar bounty operations.
- Docker Compose setup and environment examples for local development.
- CI workflow covering frontend, backend, and contract checks.

### Changed

- Established `v0.1.0` as the first documented project release baseline.

### Security

- Added initial authentication, request validation, and API security middleware foundations in the backend workspace.
